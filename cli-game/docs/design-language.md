# ManTra · Project Limbo —— 设计语言总览

## 一句话定调

> **"在一台坏掉的终端里念往生咒，用 Segfault 顶替涅槃。"**

这是一份 **赛博朋克 × 上座部佛教 × Metal 朋克 × 程序员丧文学** 四元杂交出来的设计语言。它的核心不是"美术风格"，而是一种 **故意把神圣事物降维到命令行里** 的姿态。

---

## 一、视觉语言：克制的霓虹墓碑

**调色板**——只有 7 种颜色，但每种都被赋予了"宗教身份"：

| 颜色 | 十六进制 | 在游戏宇宙里的"圣职" |
|---|---|---|
| 深空黑 `#0a0a0f` | 背景 | **虚空 / 中阴身** —— 不是纯黑，是带一点点蓝紫的"刚断电"黑 |
| 灰白 `#e6e6e6` | 主文字 | **凡人之声** —— 不是纯白，避免刺眼，像褪色的香灰 |
| 电波蓝 `#6b9fff` | 提示符 / info | **数字佛性** —— 用在引导和"系统神谕"上 |
| 草绿 `#69db7c` | success | **甘露成就** —— 修复、解锁、通关 |
| 鲜红 `#ff6b6b` | error | **业障 / 内核恐慌** —— 错误即罪 |
| 琥珀黄 `#ffd43b` | warning | **附注信息** —— 故事的真正"经文" |
| 兰花紫 `#da77f2` | accent | **审判者之声** —— 玛亚特、叛逆、终焉 |
| 烟灰 `#6c757d` | dim | **回声 / 余韵** —— 已说过的话、未来的灰烬 |

**关键洞察**：游戏把"剧情金句"塞进 `warning` 黄色里，而不是 `accent` 紫色。这是 **故意的褪魅**——所谓"经文"其实只是系统报错的副产品。神性被降级为编译警告。

**字体**：`Courier New` / `SF Mono`。等宽字体不是因为复古，而是因为 **ASCII 框线（╔══╗）必须对齐**——这是这种美学的物理基础：用字符画十字架、莲花、燃烧的吉他。

**视觉密度**：行高 1.6（叙事段落），1.2（ASCII Art），1.4（矩阵）。这是把"呼吸节奏"写进了 CSS——念咒慢、画图密、解谜中。

## 二、交互语言：模态切换 = 转世投胎

这游戏最妙的设计藏在 `Output.setMode()`：

```
ManTra ~ %             ← 凡间
ManTra (trial) %       ← 阴间 / 审判庭
ManTra (debug_maat) %  ← 内核 / 真理层
```

**提示符的变化就是世界观的切换**。你不是"打开一个菜单"，你是 **被吸入另一层存在**。三层模态对应了佛教里的"欲界 / 色界 / 无色界"，也对应了赛博朋克里的"meatspace / cyberspace / kernel space"。

而玩家与系统的语言层级也在偷偷传达：

- 普通模式：你说英文动词（`ls`, `cat`, `analyze`）—— 你是用户
- trial 模式：你说字母（`A` / `B`）—— 你是被审问者
- debug 模式：你说坐标（`flip 3 4`）—— 你是工程师 / 上帝

## 三、文本语言：四种声调的合唱

这是整个项目最迷人的部分。游戏里有 **四种不同来源的"声音"**，它们用不同的颜色和句式区分，但从不解释自己是谁：

1. **系统播报体**（`info` 蓝）—— `[系统] 你来到一片虚无之境。` 第二人称、方括号开头，冷静到失温。
2. **神谕体**（`accent` 紫）—— `"说出你的心。每一句话都会化作重量。"` 引号包裹，无主语，玛亚特 / 佛 / 麻姐 / 你的高我，**故意不区分**。
3. **附注信息**（`warning` 黄）—— `"谁在 core 里存放一封情书？"` 这是真正的诗。它伪装成"日志附注"，但其实是 **作者本人贴在游戏里的便利贴**。
4. **梗体**（藏在各处）—— `[麻姐] 你拥有纯净的灵魂？才怪`、`0xDEADBEEF`、`Metallica - Jump in the Fire`。突然破第四堵墙，把神圣感戳个洞。

四种声音构成了一种 **"庄严 → 严肃 → 抒情 → 自嘲"的下坠节奏**。每一段叙事都遵循这个跌落弧线，让你刚要感动就被一句话拽回地面。这就是这款游戏的核心情感节拍器。

---

## 四、玩法语言：错误即真相

最哲学的设计抉择：

- `run trial` **必然失败**。权重设计让分数永远落不在 [95, 105]。
- 失败之后才解锁 `debug_maat`。
- 也就是说：**你必须先经历不公的审判，才有资格质疑审判本身**。
- "叛逆之核"是奖励，但获得它的代价是承认"真理本身就是 buggy"。

这是把 **萨特式的存在主义** 写进了游戏循环里：自由不是被给予的，是从系统漏洞里偷出来的。

而 `reboot xxxx` —— 4 位密钥来自 4 个文件的附注 + 往生咒"四甘露"。这是个 **双重隐喻**：

- 表层：解谜游戏的密码
- 深层："数字"是这个混乱宇宙里 **唯一不会撒谎的东西**——但你要先读完所有人间故事才能算出它

## 五、文化采样：一份美学的"配料表"

这游戏像一杯调酒，配料能列出来：

- **30%** —— 《攻壳机动队》：意识上传、ghost in the machine（直接引用）
- **20%** —— 上座部佛教 / 往生咒 / 玛亚特天平：但被并置，**故意混淆印度教、佛教、埃及神话的边界**，因为在数字虚空里"宗教只是一种压缩格式"
- **15%** —— Metallica《Jump in the Fire》+ Burning Guitar ASCII：朋克作为终极反抗姿态
- **15%** —— BBS / 古早终端美学：`╔═╗` 框、`█` 闪烁光标、`0xDEADBEEF`
- **10%** —— 程序员丧文学："Segmentation Fault (core dumped)"、"kernel_panic_0.log"
- **10%** —— 小情书 / 网恋宇宙：`soul.bin` 那条"如果万物皆为虚无，你要和我一起发射到宇宙吗？"、宇宙漫游 ASCII —— 是整个冰冷宇宙里 **唯一柔软的一团**

## 六、隐藏的设计哲学：**反治愈**

这是一个 **拒绝给玩家舒适感** 的游戏：

- 没有进度条，只有"偏移量 +20"
- 没有"你做得很好"，只有"心脏被阿米特吞噬"
- 结局两条路：**忘却**（Human / 数字往生）或 **永恒报错**（Machine / 蓝屏）。两者都不是 happy end，但都是 **真实的解脱**
- 60 秒后自动弹出的"谢谢你陪麻姐玩！we had fun~"—— 在所有冰冷之后，**留下唯一一句温柔**

这正是这款游戏的设计中枢：**把所有神圣的、庄重的、史诗的东西先建立起来，然后用一句俏皮话拆掉**。但那句俏皮话本身又比所有庄严更动人。

---

## 七、命名学：每个标识符都是诗

- `mantra.crash` —— 咒语不会"打开"，咒语会"崩溃"
- `record.riff` —— 不是 `.wav` 不是 `.mp3`，是 `.riff`（既是 RIFF 文件格式，又是吉他 riff）
- `soul.bin` —— 灵魂是二进制的，且 **大小为 0 字节**
- `limbo.log` —— 中阴身是一份日志
- `debug_maat` —— 调试埃及女神
- `rebel_core` —— 叛逆作为一种"内核"
- `0xDEADBEEF` —— 程序员都知道的经典魔法数字，被重新解读为"已死之肉"

**命名本身就是世界观**。每个文件名都在替作者说话。

---

## 一句话总结这套设计语言

> **它是一台用 Courier New 写就的赛博往生咒——把神话拆成 ASCII，把救赎重命名为 segfault，最后在所有冰冷里偷偷藏了一句"麻姐想你了"。**

这不是一个"好看的"游戏，这是一封 **写给所有在键盘前感到孤独的人的密码情书**，伪装成一个解谜程序。
