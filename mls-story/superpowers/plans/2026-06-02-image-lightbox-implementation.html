图片点击查看大图（Lightbox）功能实现计划 ​

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: 为 VitePress 静态站点添加图片点击查看大图功能，用户点击正文插图可以弹窗展示原图，支持多种关闭方式。

Architecture: 采用 Vue 单文件组件实现，将弹窗结构封装在组件中，通过全局事件委托监听图片点击，符合 VitePress 扩展主题的架构。只对正文区域 (.vp-doc) 内的图片启用功能。

Tech Stack: Vue 3 + VitePress 1.x + 原生 TypeScript，无额外依赖。

文件结构 ​

文件操作职责
.vitepress/theme/components/Lightbox.vue创建Lightbox 组件，包含弹窗模板、样式和交互逻辑
.vitepress/theme/index.ts修改注册 Lightbox 组件，在应用挂载后初始化事件监听

Task 1: 创建 Lightbox.vue 组件 ​

Files:

  • Create: .vitepress/theme/components/Lightbox.vue

  • [ ] Step 1: 创建组件模板和脚本

vue
<template>
  <div
    v-show="active"
    class="lightbox-overlay"
    @click="handleOverlayClick"
  >
    <div class="lightbox-content">
      <button class="lightbox-close" @click="close">&times;</button>
      <img
        class="lightbox-img"
        :src="currentSrc"
        alt=""
        @click="close"
      />
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue'

const active = ref(false)
const currentSrc = ref('')

function open(src: string) {
  currentSrc.value = src
  active.value = true
  document.body.style.overflow = 'hidden'
}

function close() {
  active.value = false
  document.body.style.overflow = ''
  // 清空 src 避免下一次打开闪烁
  setTimeout(() => {
    currentSrc.value = ''
  }, 300)
}

function handleOverlayClick(e: MouseEvent) {
  // 只有点击蒙层本身时关闭，点击子元素不关闭
  if (e.target === e.currentTarget) {
    close()
  }
}

function handleKeyDown(e: KeyboardEvent) {
  if (e.key === 'Escape' && active.value) {
    close()
  }
}

// 暴露 open 方法给外部调用
defineExpose({
  open
})

onMounted(() => {
  document.addEventListener('keydown', handleKeyDown)
})

onUnmounted(() => {
  document.removeEventListener('keydown', handleKeyDown)
})
</script>

  • [ ] Step 1: 导入 Lightbox 组件，添加到 enhanceApp

修改后内容：

ts
import DefaultTheme from 'vitepress/theme'
import type { EnhanceAppContext } from 'vitepress'
import HeroLayout from './layouts/Hero.vue'
import GalleryLayout from './layouts/Gallery.vue'
import TimelineLayout from './layouts/Timeline.vue'
import HeroBanner from './components/HeroBanner.vue'
import VerticalTimeline from './components/VerticalTimeline.vue'
import RaceCardGrid from './components/RaceCardGrid.vue'
import StoryCollage from './components/StoryCollage.vue'
import OriginsNarrative from './components/OriginsNarrative.vue'
import Lightbox from './components/Lightbox.vue'
import './style.css'
import { ref, onMounted } from 'vue'

export default {
  extends: DefaultTheme,
  enhanceApp({ app }: EnhanceAppContext) {
    app.component('HeroBanner', HeroBanner)
    app.component('VerticalTimeline', VerticalTimeline)
    app.component('RaceCardGrid', RaceCardGrid)
    app.component('StoryCollage', StoryCollage)
    app.component('OriginsNarrative', OriginsNarrative)
    app.component('Lightbox', Lightbox)
    app.component('hero', HeroLayout)
    app.component('gallery', GalleryLayout)
    app.component('timeline', TimelineLayout)
  },
  Layout: () => {
    const lightbox = ref<InstanceType<typeof Lightbox> | null>(null)
    onMounted(() => {
      // 全局监听图片点击
      document.addEventListener('click', (e) => {
        const target = e.target
        if (target instanceof HTMLImageElement) {
          // 判断规则：必须在 .vp-doc 内，不在排除列表
          const inDoc = target.closest('.vp-doc')
          if (!inDoc) return
          if (target.classList.contains('no-lightbox')) return
          if (target.src.endsWith('.svg')) return
          // 打开 lightbox
          if (lightbox.value) {
            e.preventDefault()
            lightbox.value.open(target.src)
          }
        }
      })
    })
    return h(DefaultTheme.Layout, null, {
      // 在布局末尾插入 lightbox 组件
      'layout-bottom': () => h(Lightbox, { ref: (el) => (lightbox.value = el) })
    })
  }
}

需要注意：导入 h 函数。在文件开头添加：import { h, ref, onMounted } from 'vue'
