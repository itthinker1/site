VitePress File Open Build Implementation Plan ​

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: 将 VitePress 构建产物的资源路径改为相对路径，使 .vitepress/dist 中的 HTML 文件更适合通过 file:// 直接打开浏览。

Architecture: 使用 VitePress 官方 base 配置，将站点基础路径从默认 / 改为 ./。该方案只修改构建配置，不引入构建后处理脚本，也不改变文档内容结构。

Tech Stack: VitePress 1.x、Vue 3、TypeScript、npm scripts。

File Structure ​

  • Modify: .vitepress/config.ts — 添加 base: './'，让构建产物中的 CSS、JS、字体等资源使用相对路径。
  • Verify: .vitepress/dist/index.html — 构建后检查首页资源路径。
  • Verify: .vitepress/dist/majors/boston.html — 构建后检查二级页面资源路径和离线打开表现。

Task 1: 配置相对基础路径 ​

Files:

  • Modify: .vitepress/config.ts:3-6

  • [ ] Step 2: 修改 VitePress 配置

Edit .vitepress/config.ts so the top of the config becomes:

ts
import { defineConfig } from 'vitepress'

export default defineConfig({
  base: './',
  srcDir: 'docs',
  ignoreDeadLinks: true,
  title: '马拉松历史文化',
  description: '整理和展示马拉松运动的起源、发展、著名赛事和趣闻轶事',
  lang: 'zh-CN',
  head: [
    ['link', { rel: 'icon', href: '/images/hero/home-banner.jpg' }]
  ],
  themeConfig: {
    nav: [
      { text: '首页', link: '/' },
      { text: '著名赛事', link: '/majors/' },
      { text: '趣闻轶事', link: '/stories/index' }
    ],
    search: {
      provider: 'local'
    }
  }
})
  • [ ] Step 3: 重新构建

Run:

bash
npm run docs:build

Expected: 构建成功，无 VitePress 构建错误。
