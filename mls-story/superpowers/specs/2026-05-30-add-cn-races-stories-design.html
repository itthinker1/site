Design: 增加国内赛事与丰富趣闻轶事 ​

概述 ​

对马拉松百科站点做三项内容调整：增加国内赛事区块、丰富趣闻轶事、移除传奇人物栏目。

技术方案 ​

1. RaceCardGrid 组件 — href 可选化 ​

改动：RaceCardGrid.vue 的 Race 接口中 href 从必填改为可选。

渲染逻辑：有 href 时渲染 <a> 标签（可点击跳转），无 href 时渲染 <div>（纯展示卡片）。使用 v-if/v-else 分支，样式复用 .race-card 类，移除无链接卡片的 cursor: pointer。

2. 国内赛事区块 ​

位置：在 majors.md 页面「六星跑者」区块之后，新增 ## 国内知名赛事 二级标题。

数据：5 场赛事，复用 <RaceCardGrid> 组件：

赛事地点描述
十堰马拉松湖北十堰武当山脚下的特色赛事
武汉马拉松湖北武汉华中地区最大规模马拉松，横跨长江大桥
北京马拉松北京国内历史最悠久的马拉松赛事，始于1981年
上海马拉松上海国际田联金标赛事，中国最大规模马拉松之一
厦门马拉松福建厦门海滨赛道，风景优美

图片：暂无 SVG 资源，image 字段不设，RaceCardGrid 已处理空 image（显示 --color-bg 背景色占位）。

columns：设为 5，与上方六大满贯的 3 列布局形成视觉区分。

4. 传奇人物移除 ​

清理路径：

  1. 删除 docs/legends/male.md、docs/legends/female.md 及 docs/legends/ 目录
  2. 从 .vitepress/config.ts nav 移除 { text: '传奇人物', link: '/legends/male' }
  3. 从 .vitepress/theme/index.ts 移除 LegendPortrait 的 import 和 app.component 注册
  4. 删除 .vitepress/theme/components/LegendPortrait.vue
  5. 保留 docs/public/images/legends/ 图片目录（不影响运行，后续可清理）

风险 ​

  • 图片缺失：国内赛事和新增趣闻暂无 SVG，显示为纯色背景占位，不影响功能
  • proposal 修正：proposal 原文说"不修改组件代码"，实际需修改 RaceCardGrid，需更新 proposal 非目标条目

测试策略 ​

npm run dev 启动后手动验证：

  • 国内赛事区块正确渲染 5 张卡片，无链接的卡片为 div 元素
  • 趣闻轶事页面显示 7 条故事
  • 传奇人物导航入口消失
  • 无控制台报错
