马拉松 Wiki 完成设计 ​

概述 ​

完成马拉松 Wiki 的剩余工作：生成 AI 配图（先用占位图）、完善内容页面、集成 Vue 组件。

设计决策 ​

1. 图片策略 ​

决定：使用 SVG 占位图，后续替换为真实 AI 图片

原因：

  • 快速完成集成和验证
  • SVG 风格统一、加载快
  • 无需外部依赖

实现：

  • 为每种图片类型创建对应的 SVG 模板
  • 包含主题色（#2D1810、#8B1538、#F5F0E6、#D4A84B）
  • 标注图片尺寸和用途

2. Layout 组件增强 ​

决定：增强 layout 组件，自动处理组件集成

实现：

HeroLayout：

  • 自动读取 frontmatter 的 backgroundImage、title、subtitle
  • 自动集成 HeroBanner 组件
  • 简化首页 Markdown

TimelineLayout：

  • 读取页面数据中的 events 数组
  • 自动集成 VerticalTimeline 组件
  • 处理事件交替布局

GalleryLayout：

  • 支持配置使用哪种展示组件（RaceCardGrid、LegendPortrait、StoryCollage）
  • 从页面数据读取对应内容

每个页面包含：

markdown

status: final

title: 页面标题

<script setup>

  // 页面数据
}
</script>

<HeroBanner
  :background-image="frontmatter.backgroundImage"
  :title="frontmatter.title"
  :subtitle="frontmatter.subtitle"
/>
