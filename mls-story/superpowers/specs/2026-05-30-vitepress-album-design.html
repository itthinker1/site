VitePress 画册式马拉松站点设计 ​

Overview ​

将现有 MkDocs 马拉松 wiki 重构为基于 VitePress 的纯前端、纯静态画册式站点，配以复古铜版画风格的 AI 统一配图。

Visual Style ​

  • 风格： 复古铜版画/蚀刻版画风
  • 调色板：
    • 主色：深棕/黑 (#2D1810)、深红 (#8B1538)
    • 辅助色：米白 (#F5F0E6)、暖金 (#D4A84B)
  • 排版： 衬线字体为主，层级清晰

AI Illustration Prompt ​

统一模板：

{subject description}, vintage engraving style, etching print, detailed linework, sepia and crimson color palette, 19th century sports poster aesthetic, dramatic lighting, white background, high contrast

约 60 张图，按类别组织在 docs/public/images/ 下：

  • hero/（1张）
  • timeline/（5张）
  • races/（6张）
  • legends/（4张）
  • stories/（2张）
  • pages/（约42张）

Component API ​

HeroBanner ​

vue
<HeroBanner
  :background-image="'/images/hero/marathon-hero.jpg'"
  :title="'马拉松历史文化'"
  :subtitle="'从古希腊战场到现代六大满贯'"
  :show-scroll-hint="true"
/>

VerticalTimeline ​

vue
<VerticalTimeline
  :events="[
    { year: '公元前490年', title: '马拉松战役', description: '...', image: '/images/timeline/490bc.jpg' },
    // ... 共 5 个节点
  ]"
/>

RaceCardGrid ​

vue
<RaceCardGrid
  :races="[
    { name: '波士顿马拉松', location: '美国', description: '...', image: '/images/races/boston.jpg', href: '/races/majors/boston' },
    // ... 共 6 个大满贯
  ]"
  :columns="3"
/>

LegendPortrait ​

vue
<LegendPortrait
  :portrait="'/images/legends/athlete.jpg'"
  :name="'基普乔格'"
  :bio="'肯尼亚传奇跑者'"
  :achievements="['2:01:09 世界纪录', '两届奥运金牌']"
/>

StoryCollage ​

vue
<StoryCollage
  :stories="[
    { title: '有趣的纪录', content: '...', image: '/images/stories/record.jpg' },
    { title: '趣闻轶事', content: '...', image: '/images/stories/anecdote.jpg' },
  ]"
/>

Layouts ​

  • Hero： 首页 hero banner
  • Gallery： 卡片网格索引页（六大满贯、传奇人物）
  • Timeline： 垂直时间轴页（发展历程）
  • Default： 默认沉浸式叙事页

Technical Notes ​

  • 纯前端、纯静态，无 Python 依赖
  • VitePress 自定义主题，Layout 组件灵活
  • 构建输出：.vitepress/dist/
  • Legacy 归档：旧文件全部移至 legacy/ 子目录
