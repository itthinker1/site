Out of Scope & Caveats
  1. 运行时环境：未实际部署运行，未做动态渗透；所有结论基于静态代码分析 + 配置/日志文件取证。C-01 可利用性已通过代码逻辑严格论证，但未执行实际 HTTP 请求复现。

  6. CVE-2026-31072（apscheduler）：NVD 与 GitHub Advisory 描述存在矛盾，本项目初步判断不受影响，建议人工二次核实。
