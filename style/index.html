设计语言总结

两张图出自同一套视觉系统：「编辑感衬线大标题 + 手绘水彩色块 + 极简线稿插画」，整体像一本现代科技杂志的知识卡片。

1. 版式与构图

  • 标题置顶左对齐，字号极大，占据画面上方约 1/5。
  • 左右对称的二分栏结构：每栏由「英文小标签 → 中文大字主张 → 插画」自上而下排列，信息层级清晰。
  • 大量留白，背景为极浅的暖白/米白色（接近 #FAF9F6），带非常轻微的纸张质感。
  • 底部预留字幕区和小注释文字。

2. 字体

  • 中文大标题：粗黑的宋体/明体（衬线），笔画对比强，有书籍封面般的力量感。
  • 英文小标签（PPT Master、OpenAI Presentations、可编辑 PPTX）：细的无衬线体，深灰蓝色，字号小，起「分类说明」作用。
  • 字体搭配逻辑：衬线承担「观点」，无衬线承担「标签」。

3. 色彩系统

  • 主色：深墨蓝黑（#1B2433 左右），用于标题和线稿描边。
  • 双色强调：蓝色（#4A90D9 / 浅蓝 #E3EEFB）与橙色（#E8703F / 浅橘 #FCE9DC）形成冷暖对照，分别对应左右两栏。
  • 用色手法：只给标题里的关键词（「结构」「元素」「改」「互动」）换成强调色，其余保持黑色，起到视觉锚点作用。
  • 中性灰用于次要线条、占位文字条和图表柱子。

4. 插画风格

  • 扁平线稿 + 轻微手绘感：深色细描边，圆角矩形，几何化的物体（文档、窗口、图表、山与太阳的图片占位符、鼠标光标）。
  • 背景用不规则的水彩晕染色块（blob）托底，左蓝右橘，边缘柔软不规则，有淡淡的颗粒/渗透质感。
  • UI 隐喻：用浏览器窗口、编辑框（虚线框 + 四角方块控制点）、鼠标箭头、点击火花线、柱状图、编号圆点来表达「可编辑」「可交互」的概念。
  • 带有轻微的投影/纸张叠放效果，增加层次但不厚重。

5. 整体气质

轻盈、专业、友好、偏教学科普；科技概念被转译成「可触摸的 UI 小物件」，适合知识类短视频、产品对比、教程讲解。

使用小技巧

  • 文字渲染：生图模型常把中文写错，建议在提示词里把标题原文用引号明确写出（如：标题为「三种路线，三种用法」），或先生成无文字底图再用 PPT / Figma 叠加文字。
  • 保持系列一致：固定色值、字体描述和「水彩色块 + 线稿」这几个关键词，每页只替换标题和插画元素描述。
  • 换色系：只需把蓝/橙替换为另一组冷暖对照色（如青绿/珊瑚红），整套风格依然成立。

卡片式布局拟物轻毛玻璃风

卡片式布局 + 3D 软质拟物 + 轻毛玻璃，Apple / Notion / Linear 式的现代产品页，明亮、友好、专业，模块化重复，清晰的信息层级，高清细腻，无杂乱装饰。

设计语言总结

这张图和前两张是完全不同的视觉体系：前两张是「衬线大标题 + 手绘水彩 + 线稿」，这张则是「3D 软质图标 + 三栏彩色卡片 + 现代 SaaS 产品页」风格，像一张产品功能对比图。

1. 版式与构图

  • 三栏等宽并列，每栏是一张大圆角卡片，卡片之间留有均匀间距。
  • 每栏结构完全一致，自上而下为：3D 主视觉图标 → 英文大字标题 → 胶囊标签 → 白色信息块（适合）→ 米黄色信息块（特点）。
  • 严格的模块化重复，三栏只换颜色、图标和文案，方便横向对比。
  • 整体居中对称，信息密度适中，留白充足。

2. 色彩系统

每栏一个主题色，形成三色分区，且同一栏内所有元素同色系：

栏目主色标题色卡片底色胶囊标签
Chat蓝/靛蓝深靛蓝 #2B3A9E极浅蓝白渐变浅蓝底 + 深蓝字
Work绿深森林绿 #1E4D2B极浅薄荷渐变浅绿底 + 深绿字
Codex紫深紫 #3B1E8F极浅薰衣草渐变浅紫底 + 深紫字
  • 「特点」模块统一用淡米黄底 + 金棕色标题 + 金黄星标，与三栏主色形成跨栏的统一点缀。
  • 正文为深灰黑色，保证可读性。

3. 字体

  • 英文大标题：超粗圆润的无衬线体（类似 Nunito Black / Poppins ExtraBold），字号极大，颜色为各栏的深色调，有轻微的立体厚重感。
  • 胶囊标签与小标题：中文粗黑体 + 英文无衬线，加粗，居中。
  • 正文：常规字重的中文黑体，左对齐，行距舒适。
  • 「适合:」「特点:」小标题用加粗并染成对应主题色（蓝/绿/紫或金棕）。

4. 图标与插画风格

  • 3D 软质/黏土质感（Soft 3D / Claymorphism）：圆润膨胀的形体、柔和高光、轻微内阴影、温柔的环境光。
  • 主视觉图标与主题强绑定：对话气泡（Chat）、表格 + 文档 + 演示文稿三件套（Work）、终端窗口 + Git 图标（Codex）。
  • 图标下方有同色系的柔光晕，像漂浮在空中。
  • 信息块左侧配有圆形底座的小号扁平图标（气泡、文档、代码括号、星星），风格比主视觉简化。

5. 卡片与质感

  • 超大圆角（约 40–60px），细边框（与主题色同色的淡描边），外围有极柔和的大范围投影。
  • 卡片内部是极浅的纵向渐变（顶部略带主题色，向下渐白）。
  • 内部信息块是半透明白色圆角矩形，类似毛玻璃（Glassmorphism）。
  • 整体氛围：干净、明亮、友好、专业，类似 Notion / Linear / Apple 产品发布页的亲和风格。

使用小技巧

  • 中文文字容易出错：建议把每一栏的文案原文用引号写进提示词，或先生成「无文字底图」，再用 Figma / PPT 叠加文字，准确率最高。
  • 保持三栏一致：反复强调「identical structure」「modular」「same layout」，只让颜色与图标不同。
  • 换成两栏或四栏：把「三栏」改成对应数量，并为新增栏目指定新主题色（如橙色、粉色），其余描述不变。
  • 想要更扁平：把 soft 3D / claymorphism 换成 flat vector icon with subtle gradient，其余不变。
  • 与前两张的对比：如果你要把这张和之前的手绘水彩风格放进同一套 PPT，建议二选一统一风格，两者混用会显得割裂。

现代扁平化科技插画风格

科技蓝信息图，分章节、图文并茂的知识海报，常见于公众号、小红书、技术科普。

  • 信息图

风格识别

科普信息图长图（Infographic）+ 科技蓝渐变 + 扁平/轻 3D 插画 + 模块化卡片

一句话叫法

「科技蓝信息图长图风」，即竖版、分章节、图文并茂的知识海报，常见于公众号、小红书、技术科普。

风格拆解

  • 整体版式：竖版长图，自上而下按 ① ② ③ ④ ⑤ 编号分章，每章一个白色圆角卡片，阅读路径清晰。
  • 配色：深蓝到浅青的纵向渐变背景（顶部深海蓝，底部浅天蓝），卡片为白色，强调色用蓝、绿（IPv4）对比，体现「科技、网络、可信」。
  • 头部：深色星空/网络节点背景 + 发光的数字地球，标题是超大白色粗黑体，下方带青色副标题和两侧装饰线。
  • 标题标签：每章用深蓝圆角胶囊，内含白色编号圆点和白字小标题。
  • 图标：扁平矢量为主，带轻微渐变和高光（地球、路由器、盾牌、笔记本），偏「半扁平 / 轻 3D」，比上一张黏土风更克制、更写实。
  • 数据展示：大号等宽数字对比（IPv6 vs IPv4）、花括号标注、VS 圆形徽标、斜纹分栏表格，信息密度高。
  • 底部：扁平城市天际线 + 风车、汽车、高铁、医院等物联网场景，呼应结论。
