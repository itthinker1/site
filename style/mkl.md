# 设计风格概述

**风格定位**：柔和渐变 + 半扁平矢量插画（Soft Gradient UI / Semi-flat Illustration），是现代创意工作室、SaaS 类落地页的典型审美。

## 核心设计术语

- **色彩**：马卡龙粉彩色系（Pastel Palette），包含蜜桃粉、薰衣草紫、薄荷绿、天蓝、奶黄。背景用大面积弥散渐变（Mesh / Aurora Gradient），色彩过渡通透自然。
- **强调色**：高饱和琥珀黄（Accent Color）只用于 CTA 按钮和少量点缀，在柔和底色上形成唯一的视觉焦点。
- **形态**：大圆角卡片（Large Border Radius）、胶囊按钮（Pill Button）、有机曲线分割（Organic Curve / Wave Divider），避免硬直线与锐角。
- **卡片**：三张卡片分别用粉、紫、黄的同色系浅色填充（Tinted Cards），既统一又有区分。
- **层次**：大模糊、低透明度的弥散阴影（Soft Shadow）和轻微半透明质感，营造轻盈的纵深感。
- **插画**：半扁平矢量风格（Semi-flat Vector），2.5D 伪等距视角（Pseudo-isometric）。形体是圆润的基础几何形，用线性或径向渐变填充，没有真实材质、高光和体积渲染；投影是扁平椭圆或同色系弱投影。周围配有漂浮的几何装饰（Floating Shapes），增加灵动感。
- **字体**：无衬线几何字体（Geometric Sans-serif）。标题粗体，用深靛紫色（Deep Indigo）；正文细体灰色，字重对比强。
- **布局**：单列纵向叙事（Single-column Storytelling）。Hero 区左文右图，下方依次是三栏等宽卡片网格（3-column Grid）和底部 CTA。留白充裕（Generous Whitespace），小节标题居中并带圆点装饰。

## 设计语言总结

> **"轻盈、友好、有呼吸感"**

用低饱和粉彩建立亲和氛围，用大圆角和曲线传达柔软，用半扁平插画与漂浮元素增添趣味，再用唯一的暖黄强调色引导转化。信息层级清晰（Hero → 服务 → 作品 → CTA），视觉克制不拥挤，传达出**创意、年轻、专业而不失温度**的品牌调性。

## 可复用的设计规则

| 维度 | 规则 |
|---|---|
| 圆角 | 卡片 20–28px，按钮全圆角 |
| 配色 | 粉彩渐变底 + 深靛紫文字 + 单一暖黄强调 |
| 阴影 | 大模糊、低透明度、带色相的弥散投影 |
| 间距 | 区块间距大，卡片内边距宽松 |
| 插画 | 矢量几何 + 柔和渐变，2.5D 视角，不用 3D 渲染或拟物质感 |
| 分割 | 用曲线或波浪过渡区块，不用直线分隔 |
